06 / WHY CODE FOR ME

Built because
someone had to.

I discovered coding in third grade. I loved it immediately — but once that class ended, there weren't many opportunities nearby for students like me to keep going.

Code For ME grew out of that gap. It is a local program built to make computer science feel less intimidating and more accessible to Maine students.
